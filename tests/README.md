# Ptycho-FM Test Suite

This directory contains tests for the data loading components of the ptycho-fm package.

## Test Files

### `test_utils.py`
Utility functions for generating dummy HDF5 test data:
- `create_dummy_hdf5_pair()`: Creates paired `_dp.hdf5` and `_para.hdf5` files with realistic structure
- `cleanup_test_files()`: Cleans up test files

### `test_data.py`
Comprehensive tests for data loading components:

1. **`test_ptychography_dataset()`**: Tests basic PtychographyDataset functionality
   - Loading paired HDF5 files
   - Correct data shapes
   - File handle cleanup

2. **`test_combined_dataset_single_rank()`**: Tests CombinedDataset without DDP
   - Loading multiple files from directory
   - Train/val split integrity
   - Batch iteration for both train and validation

3. **`test_combined_dataset_multi_file_iteration()`**: Tests iteration through multiple files
   - Verifies all files are processed
   - Tracks samples across files
   - Ensures correct sample counts

4. **`test_split_consistency_across_epochs()`**: Tests that train/val split remains fixed across epochs
   - Verifies same samples are in train/val across different epochs
   - Tests split integrity verification method

5. **`test_combined_dataset_with_list_of_files()`**: Tests explicit file list (vs directory scanning)
   - Ensures both input methods work correctly

## Running Tests

```bash
# From project root
python tests/test_data.py
```

All tests use temporary directories and clean up automatically.

## Test Data Structure

The dummy HDF5 files created by the test utilities have the following structure:

**`*_dp.hdf5` (Diffraction Patterns)**:
- `dp`: Dataset of shape `(N, 128, 128)` - random diffraction intensities

**`*_para.hdf5` (Parameters)**:
- `object`: Dataset of shape `(1, 512, 512)` - complex object (amp + phase)
- `probe`: Dataset of shape `(8, 128, 128, 2)` - 8-mode probe (real, imag)

Number of patterns `N` is automatically calculated to match what `create_positions()` expects based on object size, probe size, and overlap parameters.

## Notes

- Tests automatically handle the mismatch between requested pattern count and the actual count generated by `create_positions()`
- Incomplete batches (remainder after division by batch_size) are dropped, so tests allow ±1 batch tolerance
- All tests pass with realistic dummy data that matches the structure of actual ptychography datasets
